# Cubic Corporation

> Cubic Corporation is a San Diego defense and public-transportation technology company. Its two
> segments are Cubic Transportation Systems (fare collection, the Umo mobility platform,
> GRIDSMART and Trafficware traffic management) and Cubic Defense (training and mission systems).

## The one public API

Cubic has exactly one API with public documentation: the **Umo IQ Public Feed**, formerly the
NextBus Public XML Feed, served by Cubic Transportation Systems.

- Base URL: https://retro.umoiq.com/service
- Documentation: https://retro.umoiq.com/xmlFeedDocs/NextBusXMLFeed.pdf (PDF, revision 1.24, 18 May 2021)
- Authentication: none. Anonymous, read-only, free to use.
- Formats: /publicXMLFeed (text/xml) and /publicJSONFeed (application/json)
- Shape: one GET endpoint per format, with a required `command` query parameter selecting the operation.

Commands: `agencyList`, `routeList`, `routeConfig`, `predictions`, `predictionsForMultiStops`,
`schedule`, `messages`, `vehicleLocations`, `vehicleLocation`.

What it returns: the transit agencies Cubic serves, their routes, stops, directions and map
polylines; live arrival and departure predictions; published timetables; active service messages;
and live GPS vehicle positions.

## Things an agent must know before calling it

- **Every response is HTTP 200, including errors.** Failure arrives as an `Error` element with a
  `shouldRetry` attribute: `true` means the agency server was initialising, wait 10 seconds and
  retry; `false` means the request is wrong.
- **Do not use the documentation's example agency.** The PDF uses `sf-muni`, which no longer
  resolves. Call `agencyList` first. Seventeen agencies were live on 2026-09-19, including
  `ttc`, `omnitrans`, `stl`, `ccrta` and `ucb`.
- **Poll at most once every 10 seconds.** Published limits: 2 MB per 20 seconds per IP, 100
  routes per `routeConfig`, 150 stops per route for `predictionsForMultiStops`, 5 predictions per
  stop, 5-minute span for `vehicleLocations`. No rate-limit headers are returned, so a client
  cannot observe its budget and must self-police.
- **All values are strings** in both formats, including coordinates and booleans.
- **In JSON, one element is an object and several are an array** (`route`, `vehicle`,
  `predictions`, `Error`). Handle both.
- Send `Accept-Encoding: gzip, deflate`; the provider documents a 50-85% size reduction.
- `Access-Control-Allow-Origin: *` is returned, so the feed is callable from a browser.

## Surfaces that exist but are not public

- **Umo IQ agency portal** (https://rider.umoiq.com/) — agency-facing, behind a login.
- **GRIDSMART API** — documented at support.gridsmart.com, which redirects to a login.
- **Trafficware support** — support.trafficware.com, same posture.
- **developer.cubic.com** — resolves, but every path 301s to www.cubic.com/coming-soon and the
  host sits behind an Imperva bot challenge. There is no Cubic developer portal today.
